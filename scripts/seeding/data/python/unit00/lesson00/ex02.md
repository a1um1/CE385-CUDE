# รับค่าแล้วทักกลับ

ตอนนี้คุณจะได้ลองรับ Input จากผู้ใช้ แล้วนำมาแสดงผลกลับออกมา

ให้เขียนโปรแกรมที่อ่านค่าหนึ่งบรรทัด แล้วแสดงผลในรูปแบบ `Hello <input>`\
โดยที่ `<input>` คือค่าที่ผู้ใช้กรอกเข้ามา

## Allowed Functions

`print`, `input`

## Expected Output

```
> 1-2-3
Hello 1-2-3
```
