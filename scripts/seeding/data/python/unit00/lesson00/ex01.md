# รู้จัก Code Editor

เราจะแนะนำให้คุณรู้จัก `Code Editor` หรือตัวแก้โค้ดที่อยู่ขวามือของหน้านี้\
โดยจะมีโค้ดเริ่มต้นให้แบบนี้

```python
print("Hello CUDE! Welcome our new student!!!")
```

กดปุ่ม **Run** ที่หัว Editor หรือกด `Shift + F5` เพื่อรันโค้ดบน Browser ได้เลย\
ถ้ารันผ่าน คุณจะเห็นผลลัพธ์ในช่อง Output ด้านล่าง

## ข้อจำกัดของการส่งคำตอบ

- โค้ดที่ Submit รันได้แค่ 1 Process
- มีการจำกัด Memory ที่ใช้ได้
- มีการจำกัดเวลาในการรัน
- ต้องไม่เกิด Error ขณะรัน
- ต้องไม่เกิด Infinite Loop หรือ Loop ที่ไม่มีวันจบ
- ต้องไม่ใช้ Resource ของเครื่องมากเกินไป
- ต้องใช้ Function ที่ได้รับอนุญาตเท่านั้น

## Allowed Functions

`print`

## Expected Output

```
Hello CUDE! Welcome our new student!!!
```

> [!CAUTION]\
> Output ต้องตรงกับ Expected Output ทุกตัวอักษร รวมถึงตัวอักษรพิเศษและช่องว่าง\
> ถ้า Output ไม่ตรง จะถือว่า Test Case นั้น Fail และข้อนั้นจะไม่ผ่านการตรวจสอบ

> [!TIP]\
> ยังไม่ต้องกังวลเรื่องจำคลังคำสั่ง ค่อย ๆ เรียนไปทีละนิดก็ทันแน่นอน
