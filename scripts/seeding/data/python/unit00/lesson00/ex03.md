# เตรียมใจก่อนลุย

ก่อนจะไปเขียนโค้ดกันจริง ๆ มีเรื่องอยากฝากไว้สักหน่อย\
เพราะหลายคนที่เพิ่งเริ่ม มักกังวลว่า "เราจะทำได้ไหม" คำตอบคือ **ทำได้แน่นอน**

## เมื่อเจอ Error

Error ไม่ใช่ศัตรู แต่เป็นเพื่อนที่คอยบอกว่าโค้ดติดตรงไหน\
ลองอ่านข้อความ Error จาก **บรรทัดสุดท้ายขึ้นไป** มักบอกบรรทัดที่มีปัญหาไว้

## ขั้นตอนแก้ปัญหา

1. อ่านโจทย์ช้า ๆ อีกครั้ง มองหาสิ่งที่โจทย์ต้องการจริง ๆ
2. แบ่งปัญหาย่อยให้เล็กลง ทำทีละส่วน
3. ลองPrintค่าออกมาดูว่าโปรแกรมคิดอะไรอยู่
4. ถ้ายังไม่ออก พักสายตาสักครู่ แล้วค่อยกลับมา

> [!TIP]\
> การเขียนโค้ดเป็นทักษะ ไม่ใช่พรสวรรค์\
> ใครยิ่งลองผิดลองถูกมาก ยิ่งเก่งเร็ว ยิ่งเจอ Error เยอะยิ่งได้เรียนรู้เยอะ

## สิ่งที่อยากให้จำ

- ถามได้ทุกเมื่อ ไม่มีคำถามไหนโง่
- เทียบกับตัวเองเมื่อวาน ไม่ใช่กับคนอื่น
- ค่อยเป็นค่อยไป วันที่มึน ๆ ก็เป็นเรื่องปกติ

พร้อมแล้วไปสนุกกับการเขียนโปรแกรมกันเลย 🚀
