# ยินดีต้อนรับสู่ CUDE 🎉

สวัสดีและยินดีต้อนรับสู่ Platform CUDE\
ระบบนี้เป็น LMS (Learning Management System) ที่พัฒนาขึ้นมาโดยเฉพาะสำหรับการเรียน Computer Engineering ระดับปริญญาตรี

## ที่นี่คือพื้นที่ปลอดภัยสำหรับการลองผิดลองถูก

ไม่มีใครเขียนโค้ดครั้งแรกแล้วไม่มี Error และการเจอ Error ก็ไม่ใช่ความผิด\
มันคือวิธีที่โปรแกรมเมอร์ทุกคนใช้เรียนรู้มาแล้วทั้งนั้น

> [!NOTE]\
> เป้าหมายของ Bootcamp นี้ไม่ใช่การจำให้ได้ทุกอย่าง\
> แต่คือการ **กล้าลอง กล้าถาม และไม่กลัวพัง**

## สิ่งที่คุณจะได้เจอ

- **ข้ออ่าน (Reading)** อย่างที่คุณกำลังอ่านอยู่ ไม่ต้องส่งคำตอบ แค่อ่านให้เข้าใจภาพรวม
- **ข้อเขียนโค้ด (Coding)** ฝึกจริงทีละข้อ จากง่ายไปยาก
- ระบบจะตรวจคำตอบให้ทันทีว่าถูกหรือไม่

## กติกาง่าย ๆ

1. อ่านโจทย์ให้ครบก่อนเริ่ม
2. ลองด้วยตัวเองก่อน ถ้าติดจริง ๆ ค่อยถามเพื่อน Google หรือผู้สอน
3. ทำผิดได้เต็มที่ แก้แล้วลองใหม่ได้เสมอ

ก่อนเริ่ม เราจะขอแนะนำการใช้งานระบบสักนิด\
ถ้าพร้อมแล้ว กด **ต่อไป** ได้เลย ขอให้สนุกนะ 🙂
