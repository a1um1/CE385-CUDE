การตรวจว่ามีข้อมูลซ้ำกันหรือไม่เป็นคำถามพื้นฐานของการทำความสะอาดข้อมูล เช่น หาบัญชีที่ลงทะเบียนซ้ำ หรือหาสินค้าที่บันทึกซ้ำในคลัง ให้เขียนฟังก์ชันรับ `list` ของจำนวนเต็ม แล้วคืน `True` ถ้ามีค่าซ้ำกันอย่างน้อยหนึ่งคู่ หรือ `False` ถ้าทุกค่าแตกต่างกัน

## Requirements

- ซ้ำหนึ่งคู่ก็เพียงพอแล้ว
- ให้ใช้ `set` ตรวจขนาด

## Prototype

```python
has_duplicate(nums: list[int]) -> bool
```

## Expected Output

```
> 4
> 1
> 2
> 3
> 1
True
```
