# Dictionaries & Sets

`dict` เก็บคู่ key–value ใช้ key ในการเข้าถึงและนับจำนวน (`{ "cat": 2 }`)\
`set` เก็บค่าที่ไม่ซ้ำ ตรวจสมาชิกเร็ว และหาส่วนร่วม/ต่างของสองชุดได้\
ทั้งสองชนิด **ไม่มีการันตีลำดับ** — วนดูค่าได้ แต่ห้ามพึ่งลำดับที่ได้

ไปค้นต่อ: `python dict`, `python set`, `python collections.Counter`
