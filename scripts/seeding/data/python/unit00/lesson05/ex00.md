# Dictionaries & Sets

เมื่อข้อมูลมีปริมาณมาก การค้นหาแบบไล่ดูทีละตัวอาจช้าเกินไป `dict` และ `set` ช่วยให้ค้นหา ตรวจสอบ และนับความถี่ได้อย่างรวดเร็ว ต่างกันที่รูปแบบการเก็บข้อมูล จึงต้องเลือกใช้ให้ตรงกับงาน

- `dict` เก็บคู่ key–value ใช้ key ในการเข้าถึงและนับจำนวน (`{ "cat": 2 }`)
- `set` เก็บค่าที่ไม่ซ้ำ ตรวจว่ามีสมาชิกไหมได้เร็ว และหาส่วนร่วม/ส่วนต่างของสองชุดได้
- ทั้งสองชนิด **ไม่การันตีลำดับ** วนดูค่าได้ แต่ห้ามพึ่งลำดับที่ได้

> [!NOTE]\
> Keyword `python dict`, `python set`, `python collections.Counter`
