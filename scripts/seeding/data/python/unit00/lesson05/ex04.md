testerCode: |
  for w in word_freq(input()):
      print(w)
testCase:
  - input: "the cat and the dog"
    output: "the\nand\ncat\ndog"
    public: true
  - input: "a a b b c"
    output: "a\nb\nc"
  - input: "x y x y z"
    output: "x\ny\nz"
  - input: "zebra apple zebra banana apple apple"
    output: "apple\nzebra\nbanana"
---

คืน list ของคำใน `text` (พิมพ์เล็กทั้งหมด แต่ละคำหนึ่งครั้ง) เรียงตามความถี่จากมากไปน้อย ถ้าเท่ากันเรียง a-z

## Prototype

```
word_freq(text: str) -> list[str]
```
