Anagram คือข้อความที่เรียงตัวอักษรใหม่แล้วได้อีกข้อความหนึ่ง เช่น `listen` กับ `silent` หรือ `Clint Eastwood` กับ `old west action` การตรวจสอบแบบนี้ใช้ในเกมคำศัพท์และการตรวจความถูกต้องของข้อมูล ให้เขียนฟังก์ชันตรวจสอบว่าข้อความสองอันเป็น anagram กันหรือไม่ โดยไม่สนใจช่องว่างและตัวพิมพ์เล็ก/ใหญ่

## Requirements

- anagram คือเรียงตัวอักษรใหม่แล้วได้เหมือนกัน
- ไม่สนใจตัวพิมพ์เล็ก/ใหญ่
- ไม่นับช่องว่าง

## Prototype

```python
anagram(a: str, b: str) -> bool
```

## Expected Output

```
> listen
> silent
True
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
