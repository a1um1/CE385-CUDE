การนับความถี่ของคำช่วยหาคำที่สำคัญหรือหัวข้อของข้อความ เช่น คำที่ถูกพูดถึงมากที่สุดในข่าว ให้เขียนฟังก์ชันรับข้อความ แล้วคืน `list` ของคำเรียงตามความถี่จากมากไปน้อย โดยไม่สนใจตัวพิมพ์เล็ก/ใหญ่ และแต่ละคำปรากฏแค่ครั้งเดียว ถ้าความถี่เท่ากันให้เรียงตามตัวอักษร a–z

## Requirements

- รวมคำโดยไม่สนใจตัวพิมพ์เล็ก/ใหญ่ (พิมพ์เล็กทั้งหมด)
- แต่ละคำปรากฏในผลลัพธ์หนึ่งครั้ง
- ถ้าความถี่เท่ากัน เรียงตามตัวอักษร a–z
- ให้ใช้ `dict` ในการนับความถี่

## Prototype

```python
word_freq(text: str) -> list[str]
```

## Expected Output

```
> the cat and the dog
the
and
cat
dog
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
