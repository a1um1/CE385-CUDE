การหาค่าที่ไม่ซ้ำตัวแรกต้องรู้ก่อนว่าตัวอักษรแต่ละตัวปรากฏกี่ครั้ง เช่น ใน `abac` ตัว `b` เป็นตัวแรกที่ปรากฏเพียงครั้งเดียว ให้เขียนฟังก์ชันรับข้อความ แล้วคืนตัวอักษรตัวแรกที่ปรากฏเพียงครั้งเดียวเรียงตามลำดับในข้อความ หรือคืนข้อความว่างถ้าไม่มีตัวไหนไม่ซ้ำเลย

## Requirements

- ดูตัวอักษรตามลำดับในข้อความ แล้วคืนตัวแรกที่ไม่ซ้ำ
- ถ้าไม่มีตัวไหนไม่ซ้ำ ให้คืนข้อความว่าง
- ให้ใช้ `Counter` นับก่อน แล้วค่อยวนหา

## Prototype

```python
first_unique(text: str) -> str
```

## Expected Output

```
> abac
b
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
