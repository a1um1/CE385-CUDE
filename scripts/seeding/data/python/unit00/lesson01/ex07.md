testCase:
  - input: "1234"
    output: "4"
  - input: "7"

  - print

รับจำนวนเต็มบวก แล้วแสดงเฉพาะหลักสุดท้าย (หลักหน่วย)

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> 1234
4
```

> [!TIP]\
> หลักสุดท้ายของจำนวนเต็มคือ `n % 10`
