ให้เขียนฟังก์ชัน `to_hms` ที่รับเวลาเป็นจำนวนวินาที แล้วคืนข้อความในรูปแบบ `H:M:S`

ตัวอย่าง: 3661 วินาที = 1 ชั่วโมง 1 นาที 1 วินาที → `"1:1:1"`

## Prototype

```
to_hms(total_seconds: int) -> str
```

- **ชื่อฟังก์ชัน**: `to_hms`
- **พารามิเตอร์**: `total_seconds` เป็นจำนวนเต็ม
- **ค่าที่คืนกลับ**: ข้อความรูปแบบ `H:M:S`

> [!TIP]\
> ใช้ `//` หาจำนวนชั่วโมง/นาที และ `%` หาเศษที่เหลือ แล้วต่อข้อความด้วย `str(...)`

## Allowed Functions

`int`, `str`

## Expected Output

```
> 3661
1:1:1
```
