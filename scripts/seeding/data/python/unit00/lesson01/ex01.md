---
title: EX01 Say Hello
type: code
testCase:
  - input: "CUDE"
    output: "Hello, CUDE!"
  - input: "Somchai"
    output: "Hello, Somchai!"
allowedFunctions:
  - input
  - print
---

ในข้อนี้คุณจะได้ฝึกอ่านค่าที่ผู้ใช้กรอกเข้ามาด้วย Function `input` แล้วนำมาแสดงผลด้วย `print`

ให้เขียนโปรแกรมรับ **ชื่อ** จากผู้ใช้ 1 บรรทัด แล้วแสดงคำทักทายในรูปแบบ `Hello, <name>!`

## Allowed Functions

`input`, `print`

## Expected Output

```
> CUDE
Hello, CUDE!
```

> [!NOTE]\
> ค่าที่ได้จาก `input` เป็นชนิด `str` (ข้อความ) เสมอ
