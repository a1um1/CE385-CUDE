# ก่อนลงมือ: ตัวแปรและตัวดำเนินการ

โค้ดทุกบรรทัดทำงานกับ "ข้อมูล" การเก็บข้อมูลไว้ใช้ซ้ำเรียกว่า **ตัวแปร (Variable)**

## ตัวแปรคืออะไร

คิดว่าตัวแปรคือกล่องที่ติดป้ายชื่อไว้ ข้างในใส่ค่าได้

```python
name: str = "CUDE"
age: int = 1
```

- `name` และ `age` คือชื่อกล่อง
- `"CUDE"` และ `1` คือค่าที่ใส่ไว้ข้างใน
- `: str` และ `: int` คือชนิดข้อมูลของกล่องนั้น

## ชนิดข้อมูลพื้นฐาน

| ชนิด | ตัวอย่าง | ความหมาย |
| --- | --- | --- |
| `int` | `42` | จำนวนเต็ม |
| `float` | `3.14` | จำนวนทศนิยม |
| `str` | `"hello"` | ข้อความ |
| `bool` | `True` | จริง / เท็จ |

> [!NOTE]\
> ค่าที่ได้จาก `input` เป็น `str` เสมอ ถ้าอยากได้ตัวเลขต้องแปลงด้วย `int(...)`

## ตัวดำเนินการ (Operators)

- `+ - * /` บวก ลบ คูณ หาร
- `//` หารปัดเศษทิ้ง, `%` เศษที่เหลือ
- `**` ยกกำลัง

```python
print(7 // 2)   # 3
print(7 % 2)    # 1
```

ไม่ต้องจำทั้งหมดตอนนี้ เจอในโจทย์แล้วค่อย ๆ เข้าใจทีละข้อก็พอ ลุยได้เลย!
