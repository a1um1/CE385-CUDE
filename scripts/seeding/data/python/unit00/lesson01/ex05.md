ให้เขียนฟังก์ชัน `swap` ที่รับจำนวนเต็มสองจำนวน แล้วคืนค่าทั้งสองโดย **สลับลำดับกัน**

## Prototype

```
swap(a: int, b: int) -> tuple[int, int]
```

- **ชื่อฟังก์ชัน**: `swap`
- **พารามิเตอร์**: `a`, `b` เป็นจำนวนเต็ม
- **ค่าที่คืนกลับ**: สองค่า สลับที่กัน

> [!TIP]\
> ใน Python คืนค่าหลายค่าได้ด้วย `return b, a`

## Allowed Functions

`int`, `tuple`

## Expected Output

```
> 1
> 2
2
1
```
