---
title: EX09 Total Price
type: code
testCase:
  - input: "25\n4"
    output: "Total: 100"
  - input: "10\n3"
    output: "Total: 30"
allowedFunctions:
  - input
  - int
  - print
  - str
---

ร้านค้าแห่งหนึ่งขายสินค้าราคาชิ้นละ `price` บาท

รับ `price` และ `quantity` (บรรทัดละ 1 จำนวน) แล้วแสดงราคารวมในรูปแบบ `Total: <total>`

## Allowed Functions

`input`, `int`, `print`, `str`

## Expected Output

```
> 25
> 4
Total: 100
```

> [!NOTE]\
> ต้องแปลงผลรวมเป็นข้อความก่อนต่อกับ `"Total: "` เช่น `"Total: " + str(total)`
