ให้เขียนฟังก์ชัน `sum_digits` ที่รับจำนวนเต็มบวกที่มี 3 หลัก แล้วคืนผลรวมของทั้ง 3 หลัก

ตัวอย่าง: 385 → 3 + 8 + 5 = 16

## Prototype

```
sum_digits(n: int) -> int
```

- **ชื่อฟังก์ชัน**: `sum_digits`
- **พารามิเตอร์**: `n` เป็นจำนวนเต็ม 3 หลัก
- **ค่าที่คืนกลับ**: ผลรวมของทั้ง 3 หลัก

> [!TIP]\
> ใช้ `n // 100`, `n // 10 % 10` และ `n % 10` เพื่อแยกแต่ละหลัก

## Allowed Functions

`int`

## Expected Output

```
> 385
16
```
