---
title: EX10 Repeat Word
type: code
testCase:
  - input: "Hi\n3"
    output: "HiHiHi"
  - input: "ab\n2"
    output: "abab"
  - input: "Z\n1"
    output: "Z"
allowedFunctions:
  - input
  - int
  - print
---

รับคำ (บรรทัดแรก) และจำนวนเต็ม `n` (บรรทัดที่สอง) แล้วแสดงคำนั้นซ้ำกัน `n` ครั้ง

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> Hi
> 3
HiHiHi
```

> [!TIP]\
> ข้อความใน Python คูณด้วยจำนวนเต็มได้ด้วยตัวดำเนินการ `*`
