ร้านค้าแห่งหนึ่งขายสินค้าราคาชิ้นละ `price` บาท

ให้เขียนฟังก์ชัน `total_price` ที่รับราคาต่อชิ้นและจำนวนชิ้น แล้วคืนข้อความราคารวมในรูปแบบ `Total: <total>`

## Prototype

```
total_price(price: int, quantity: int) -> str
```

- **ชื่อฟังก์ชัน**: `total_price`
- **พารามิเตอร์**: `price`, `quantity` เป็นจำนวนเต็ม
- **ค่าที่คืนกลับ**: ข้อความ `Total: <ราคารวม>`

> [!NOTE]\
> ต้องแปลงผลรวมเป็นข้อความก่อนต่อกับ `"Total: "` เช่น `"Total: " + str(total)`

## Allowed Functions

`int`, `str`

## Expected Output

```
> 25
> 4
Total: 100
```
