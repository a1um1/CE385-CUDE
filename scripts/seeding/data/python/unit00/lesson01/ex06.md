  - input: "3661"

รับเวลาเป็นจำนวนวินาที (จำนวนเต็ม) แล้วแปลงและแสดงผลในรูปแบบ `H:M:S`

ตัวอย่าง: 3661 วินาที = 1 ชั่วโมง 1 นาที 1 วินาที

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> 3661
1:1:1
```

> [!TIP]\
> ใช้ `//` หาจำนวนชั่วโมง/นาที และ `%` หาเศษที่เหลือ
