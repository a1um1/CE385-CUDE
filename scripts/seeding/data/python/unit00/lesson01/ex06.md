ให้เขียนฟังก์ชัน `to_fahrenheit` ที่รับอุณหภูมิหน่วยเซลเซียส (จำนวนเต็ม) แล้วคืนอุณหภูมิหน่วยฟาเรนไฮต์ (จำนวนเต็ม)

ให้ใช้สูตรจำนวนเต็ม: `f = c * 9 // 5 + 32`

## Prototype

```
to_fahrenheit(c: int) -> int
```

- **ชื่อฟังก์ชัน**: `to_fahrenheit`
- **พารามิเตอร์**: `c` เป็นจำนวนเต็ม (เซลเซียส)
- **ค่าที่คืนกลับ**: อุณหภูมิฟาเรนไฮต์

> [!NOTE]\
> `//` คือการหารแบบปัดเศษทิ้ง (integer division)

## Allowed Functions

`int`

## Expected Output

```
> 25
77
```
