ให้เขียนฟังก์ชัน `area` ที่รับความกว้างและความยาวของสี่เหลี่ยมมุมฉาก แล้วคืนค่าพื้นที่

สูตร: `area = width * height`

## Prototype

```
area(width: int, height: int) -> int
```

- **ชื่อฟังก์ชัน**: `area`
- **พารามิเตอร์**: `width`, `height` เป็นจำนวนเต็ม
- **ค่าที่คืนกลับ**: พื้นที่ของสี่เหลี่ยม

## Allowed Functions

`int`

## Expected Output

```
> 4
> 6
24
```
