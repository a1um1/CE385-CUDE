ให้เขียนฟังก์ชัน `repeat` ที่รับคำและจำนวนเต็ม `n` แล้วคืนคำนั้นซ้ำกัน `n` ครั้ง

## Prototype

```
repeat(word: str, n: int) -> str
```

- **ชื่อฟังก์ชัน**: `repeat`
- **พารามิเตอร์**: `word` เป็นข้อความ, `n` เป็นจำนวนเต็ม
- **ค่าที่คืนกลับ**: ข้อความที่ซ้ำกัน `n` ครั้ง

> [!TIP]\
> ข้อความใน Python คูณด้วยจำนวนเต็มได้ด้วยตัวดำเนินการ `*`

## Allowed Functions

`str`, `int`

## Expected Output

```
> Hi
> 3
HiHiHi
```
