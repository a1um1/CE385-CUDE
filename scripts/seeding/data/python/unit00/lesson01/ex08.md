type: code
testCase:
  - input: "385"
    output: "16"
  - input: "100"
    output: "1"

  - input
  - int
  - print

รับจำนวนเต็มบวกที่มี 3 หลัก แล้วแสดงผลรวมของทั้ง 3 หลัก

ตัวอย่าง: 385 → 3 + 8 + 5 = 16

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> 385
16
```

> [!TIP]\
> ใช้ `n // 100`, `n // 10 % 10` และ `n % 10` เพื่อแยกแต่ละหลัก
