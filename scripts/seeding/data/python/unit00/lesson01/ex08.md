ให้เขียนฟังก์ชัน `last_digit` ที่รับจำนวนเต็มบวก แล้วคืนค่าหลักสุดท้าย (หลักหน่วย)

## Prototype

```
last_digit(n: int) -> int
```

- **ชื่อฟังก์ชัน**: `last_digit`
- **พารามิเตอร์**: `n` เป็นจำนวนเต็ม
- **ค่าที่คืนกลับ**: หลักสุดท้ายของ `n`

> [!TIP]\
> หลักสุดท้ายของจำนวนเต็มคือ `n % 10`

`int`
