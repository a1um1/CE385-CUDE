# รู้จักฟังก์ชัน (Function)

ฟังก์ชันคือ "ชุดคำสั่งที่ตั้งชื่อไว้" แล้วเรียกใช้ซ้ำได้\
แทนที่จะเขียนโค้ดเดิมซ้ำ ๆ เราเขียนครั้งเดียว ตั้งชื่อ แล้วเรียกชื่อนั้นได้เลย

```python
def add(a: int, b: int) -> int:
    return a + b

print(add(2, 3))   # 5
```

- `def` คือคำสั่งสร้างฟังก์ชัน
- `add` คือชื่อฟังก์ชัน
- `a: int`, `b: int` คือพารามิเตอร์ พร้อมบอกชนิดข้อมูล (type)
- `-> int` คือชนิดของค่าที่ฟังก์ชันคืนกลับ
- `return` คือค่าที่ฟังก์ชันคืนกลับออกไป

## Python แบบมี Type

Python เขียนชนิดข้อมูลกำกับไว้ได้ เพื่อให้อ่านง่ายและลดข้อผิดพลาด

```python
name: str = "CUDE"
age: int = 1
scores: list[int] = [10, 20, 30]
```

ชนิดที่เจอบ่อย: `int`, `str`, `float`, `bool`, `list[int]`

## Prototype คืออะไร

**Prototype** (หรือ signature) คือหน้าตาของฟังก์ชัน ว่าชื่ออะไร รับค่าอะไรเข้ามา และคืนค่าอะไรกลับออกไป

ตัวอย่างของ `add` เขียนเป็น prototype ได้ว่า

```
add(a: int, b: int) -> int
```

อ่านว่า: ฟังก์ชันชื่อ `add` รับ `a` กับ `b` เป็นจำนวนเต็ม และคืนค่าจำนวนเต็ม

## หัวใจของการทำโจทย์ในชุดนี้

โจทย์ทุกข้อจะบอก **prototype** มาให้ และมีโครงฟังก์ชันตั้งต้น (starter code) เตรียมไว้แล้ว\
หน้าที่ของคุณคือ **เติมโค้ดในฟังก์ชัน** ให้ทำงานถูกต้อง

> [!NOTE]\
> ตั้งชื่อฟังก์ชัน พารามิเตอร์ และ type ให้ตรงกับ prototype เสมอ\
> และให้ **`return` ค่าออกไป** ระบบจะเป็นคนเรียกฟังก์ชันและตรวจคำตอบให้\
> ไม่ต้อง `input` หรือ `print` เองในฟังก์ชัน

## ตัวอย่างให้อ่านก่อน

```python
def greet(name: str) -> str:
    return "Hello, " + name
```

ถ้าเรียก `greet("CUDE")` จะได้ค่าเป็น `"Hello, CUDE"`

ยังไม่ต้องกังวลถ้ายังไม่คุ้น เดี๋ยวได้ฝึกทุกข้อเลย กดต่อไปได้เลย!
