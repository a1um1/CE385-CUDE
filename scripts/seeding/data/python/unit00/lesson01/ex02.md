---
title: EX02 Add Two Numbers
type: code
testCase:
  - input: "3\n5"
    output: "8"
  - input: "10\n20"
    output: "30"
  - input: "0\n0"
    output: "0"
allowedFunctions:
  - input
  - int
  - print
---

ให้เขียนโปรแกรมรับจำนวนเต็ม 2 จำนวน (บรรทัดละ 1 จำนวน) แล้วแสดงผลรวมออกมา

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> 3
> 5
8
```

> [!NOTE]\
> ค่าที่ได้จาก `input` เป็น `str` ต้องแปลงเป็นจำนวนเต็มด้วย `int(...)` ก่อนนำมาบวกกัน
