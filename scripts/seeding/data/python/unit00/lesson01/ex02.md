ให้เขียนฟังก์ชัน `greet` ที่คืนคำทักทายในรูปแบบ `Hello, <name>!`

## Prototype

```
greet(name: str) -> str
```

- **ชื่อฟังก์ชัน**: `greet`
- **พารามิเตอร์**: `name` เป็นข้อความ
- **ค่าที่คืนกลับ**: ข้อความทักทาย

> [!NOTE]\
> ค่าที่ได้จาก `input` เป็นชนิด `str` เสมอ และเขียนแค่ตัวฟังก์ชัน ไม่ต้อง `input` เอง

## Allowed Functions

`str`

## Expected Output

```
> CUDE
Hello, CUDE!
```
