# Numbers & Math

โจทย์เชิงตัวเลขส่วนใหญ่วนเวียนอยู่กับการหาร การเอาเศษ และการแปลงชนิดของข้อมูล การคล่องเครื่องมือเหล่านี้จะช่วยให้แก้อัลกอริทึมคณิตศาสตร์ได้เร็วขึ้น และยังเป็นพื้นฐานของการทำงานกับเวลา เงิน และหน่วยวัด

- `%` หารเอาเศษ, `//` หารปัดเศษทิ้ง
- `str(n)` / `int(s)` เปลี่ยนระหว่างเลขกับข้อความได้ทุกเมื่อ
- ใช้ลูปถอดหลักทีละหลักด้วย `n % 10`
- สร้างเลขกลับด้านได้ด้วย `rev * 10 + หลัก`

> [!NOTE]\
> Keyword `python modulo`, `python reverse integer`, `python gcd`
