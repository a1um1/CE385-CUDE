# Numbers & Math

จัดการเลขด้วย `%` (หารเอาเศษ) และ `//` (หารปัดเศษ)\
`str(n)` / `int(s)` เปลี่ยนชนิดของเลขและข้อความได้ทุกเมื่อ\
ใช้ loop ถอดหลักทีละหลัก (`n % 10`) แล้วสร้างเลขกลับด้านได้ (`rev * 10 + หลัก`)

ไปค้นต่อ: `python modulo`, `python reverse integer`, `python gcd`
