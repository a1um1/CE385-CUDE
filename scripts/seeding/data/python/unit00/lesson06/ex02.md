จำนวนสมบูรณ์คือจำนวนเต็มบวกที่เท่ากับผลรวมของตัวหารแท้ของมัน ตัวหารแท้คือตัวหารที่ไม่รวมตัวมันเอง เช่น 6 มีตัวหารแท้ 1, 2, 3 ซึ่งรวมกันได้ 6 พอดี ให้เขียนฟังก์ชันตรวจสอบว่า `n` เป็นจำนวนสมบูรณ์หรือไม่ แล้วคืน `True` หรือ `False`

## Requirements

- ตัวหารแท้คือตัวหารที่ไม่นับตัวมันเอง
- ไล่ตรวจตัวหารได้ แต่ต้องระวังเรื่องความเร็วกับค่าที่มาก

## Prototype

```python
perfect_number(n: int) -> bool
```

## Expected Output

```
> 6
True
```
