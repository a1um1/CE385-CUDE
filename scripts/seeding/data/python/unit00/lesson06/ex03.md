Armstrong number คือจำนวนที่เท่ากับผลรวมของหลักแต่ละตัวยกกำลังด้วยจำนวนหลักของมัน เช่น 153 มี 3 หลัก และ `1³ + 5³ + 3³ = 153` พอดี ให้เขียนฟังก์ชันตรวจสอบว่า `n` ที่รับเข้ามาเป็น Armstrong number หรือไม่ แล้วคืน `True` หรือ `False`

## Requirements

- Armstrong number คือเลขที่เท่ากับผลรวมของหลักแต่ละตัวยกกำลังด้วยจำนวนหลัก
- ตัวอย่าง: `153 = 1³+5³+3³`

## Prototype

```python
armstrong(n: int) -> bool
```

## Expected Output

```
> 153
True
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
