เลขฐานสองแทนค่าด้วยเพียงสองหลัก 0 กับ 1 เป็นภาษาที่คอมพิวเตอร์ทำงานจริง ๆ ให้เขียนฟังก์ชันแปลงจำนวนเต็ม `n` เป็นข้อความเลขฐานสอง เช่น 10 กลายเป็น `1010` โดยใช้วิธีหารด้วย 2 แล้วเก็บเศษทีละหลัก ห้ามใช้ `bin()` ที่ Python มีให้

## Requirements

- ห้ามใช้ `bin()`
- หาด้วยการหารด้วย 2 แล้วเก็บเศษทีละหลัก
- ผลลัพธ์ไม่มีคำนำหน้าหรือช่องว่าง

## Prototype

```python
decimal_to_binary(n: int) -> str
```

## Expected Output

```
> 10
1010
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
