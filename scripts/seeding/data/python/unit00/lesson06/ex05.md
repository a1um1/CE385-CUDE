การกลับหลักของตัวเลขเป็นโจทย์ที่ดูง่ายแต่มีจุดพลาดซ่อนอยู่ เช่น ค่าติดลบต้องกลับเครื่องหมายตาม และหลักศูนย์ที่ต่อท้ายจะหายไปอย่าง 120 กลายเป็น 21 ให้เขียนฟังก์ชันรับจำนวนเต็ม `n` แล้วคืนตัวเลขที่กลับหลัก เช่น `123` กลายเป็น `321`

## Requirements

- ถ้า `n` ติดลบ ผลลัพธ์ต้องติดลบด้วย
- หลัก 0 ที่อยู่ท้ายเลขจะหายไปเมื่อกลับด้าน
- ให้ใช้ `% 10` ถอดหลักทีละหลัก

## Prototype

```python
reverse_int(n: int) -> int
```

## Expected Output

```
> 123
321
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
