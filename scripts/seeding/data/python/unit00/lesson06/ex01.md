ตัวคูณร่วมน้อย (LCM) คือจำนวนเต็มที่น้อยที่สุดที่หารด้วยทั้ง `a` และ `b` ลงตัว เช่น LCM ของ 4 และ 6 คือ 12 ใช้หาช่วงเวลาที่เหตุการณ์สองอย่างมาตรงกัน ให้เขียนฟังก์ชันหา LCM โดยใช้สูตร `a * b // gcd` ซึ่งต้องหา GCD ด้วยวิธีของตัวเองก่อน ห้ามใช้ `math.lcm`

## Requirements

- ห้ามใช้ `math.lcm`
- หา gcd ด้วยวิธีของตัวเองก่อน แล้วใช้สูตร `a * b // gcd`

## Prototype

```python
lcm(a: int, b: int) -> int
```

## Expected Output

```
> 4
> 6
12
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
