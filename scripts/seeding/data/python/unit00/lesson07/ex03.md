การรวมค่าตามแนวตั้งของตารางช่วยสรุปข้อมูลเป็นรายคอลัมน์ เช่น หายอดขายรวมของแต่ละเดือนจากตารางยอดขาย ให้เขียนฟังก์ชันคืนผลรวมของสมาชิกในหลักที่ `col` (นับจาก 0) ของ `matrix` โดยดึงสมาชิกตำแหน่งเดียวกันของทุกแถวมาบวกกัน

## Requirements

- หยิบ `row[col]` ของทุกแถวมาบวกกัน
- ทุกแถวยาวเท่ากันเสมอ

## Prototype

```python
column_sum(matrix: list[list[int]], col: int) -> int
```

## Expected Output

```
> 2
> 1 2 3
> 4 5 6
> 1
7
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
