  n = int(input())
  matrix = []
  for _ in range(n):
      matrix.append([int(x) for x in input().split()])
  for v in flatten(matrix):
      print(v)

งานกับข้อมูล 2 มิติ เช่น ตาราง มักต้องทำให้เป็น list หนึ่งมิติก่อนนำไปประมวลผลต่อ เช่น การไล่เรียงทุกเซลล์ของตาราง ให้เขียนฟังก์ชันรวมสมาชิกทุกตัวของ `matrix` เป็น list เดียว เรียงตามแถวบนลงล่าง ซ้ายไปขวา

## Requirements

- เรียงตามลำดับแถวบนลงล่าง ซ้ายไปขวา
- ทำได้ในหนึ่งบรรทัดด้วย comprehension ซ้อน loop

## Prototype

```python
flatten(matrix: list[list[int]]) -> list[int]
```
