list comprehension ช่วยเขียนลูปที่ทั้งกรองและแปลงค่าได้ในบรรทัดเดียว แทนการสร้าง list ด้วยลูปยาว ๆ ให้เขียนฟังก์ชันคืน `list` ของกำลังสองของจำนวนคี่ใน `nums` โดยคงลำดับเดิม และต้องเขียนด้วย list comprehension เท่านั้น

## Requirements

- เลือกเฉพาะจำนวนคี่ แล้วยกกำลังสอง
- **ต้องเขียนด้วย list comprehension**

## Prototype

```python
square_odds(nums: list[int]) -> list[int]
```

## Expected Output

```
> 4
> 1
> 2
> 3
> 4
1
9
```
