# Nested Data & Comprehension

`list` ใน `list` คือตาราง 2 มิติ เข้าถึงด้วย `matrix[r][c]`\
list comprehension ย่อการสร้าง list: `[x * 2 for x in nums if x > 0]`\
`zip(a, b)` จับคู่สมาชิกตำแหน่งเดียวกันเป็น tuple
