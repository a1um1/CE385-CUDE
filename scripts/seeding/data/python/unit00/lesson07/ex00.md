# Nested Data & Comprehension

ข้อมูลจริงมักซ้อนกันหลายชั้น ตั้งแต่ตารางในสเปรดชีตไปจนถึงพิกเซลของรูปภาพ การจัดการข้อมูลซ้อนและการใช้เทคนิคย่อลูปจะช่วยให้โค้ดสั้นลงและอ่านเข้าใจง่ายขึ้น

- `list` ใน `list` คือตาราง 2 มิติ เข้าถึงด้วย `matrix[r][c]`
- list comprehension ย่อการสร้าง list: `[x * 2 for x in nums if x > 0]`
- `zip(a, b)` จับคู่สมาชิกตำแหน่งเดียวกันเป็น tuple

> [!NOTE]\
> Keyword `python list comprehension`, `python 2d list`, `python zip`
