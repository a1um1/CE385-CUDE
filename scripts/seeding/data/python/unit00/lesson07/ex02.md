การสลับแถวเป็นหลักของเมทริกซ์ (transpose) ใช้ในการมองข้อมูลคนละมุม เช่น การสลับตารางเปรียบเทียบรายจ่ายรายเดือนกับรายจ่ายรายประเภท ให้เขียนฟังก์ชันคืนเมทริกซ์ที่สลับแถวเป็นหลัก โดยสมาชิก `matrix[r][c]` ย้ายไปอยู่ `res[c][r]` และทุกแถวของเมทริกซ์ตั้งต้นยาวเท่ากันเสมอ

## Requirements

- `matrix[r][c]` กลายเป็น `res[c][r]`
- ทุกแถวยาวเท่ากันเสมอ
- ลองใช้ `zip(*matrix)`

## Prototype

```python
transpose(matrix: list[list[int]]) -> list[list[int]]
```

## Expected Output

```
> 2
> 1 2 3
> 4 5 6
1 4
2 5
3 6
```
