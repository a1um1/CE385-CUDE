การตรวจสอบว่าข้อมูลเรียงลำดับแล้วหรือยังเป็นจุดเริ่มต้นของหลายอัลกอริทึม เช่น การตัดสินใจว่าจะใช้ binary search ได้หรือไม่ ให้เขียนฟังก์ชันตรวจสอบว่า `nums` เรียงจากน้อยไปมากหรือไม่ โดย list ว่างถือว่าเรียงแล้ว และค่าที่เท่ากันถือว่าเรียงถูกต้อง ห้ามใช้ `sorted` หรือ `sort`

## Requirements

- array ว่างถือว่าเรียงแล้ว
- ค่าที่เท่ากันถือว่าเรียงถูกต้อง
- ห้ามใช้ `sorted` / `sort`

## Prototype

```python
is_sorted(nums: list[int]) -> bool
```

## Expected Output

```
> 1 2 3
True
```
