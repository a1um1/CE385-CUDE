title: EX05 Is Sorted
type: code
testerCode: |
  nums = [int(x) for x in input().split()]
  print(is_sorted(nums))
testCase:
  - input: "1 2 3"
    output: "True"
    public: true
  - input: "1 3 2"
    output: "False"
    public: true
  - input: "\n"
    output: "True"
  - input: "5 5 5"
    output: "True"
  - input: "9 8"
    output: "False"
---

คืน `True` ถ้า `nums` เรียงจากน้อยไปมากอยู่แล้ว (array ว่างถือว่าเรียงแล้ว) ห้ามใช้ `sorted`/`sort`

## Prototype

```
is_sorted(nums: list[int]) -> bool
```

## Expected Output

```

> 1 2 3
True
```
