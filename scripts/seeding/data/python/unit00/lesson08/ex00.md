แฟกทอเรียลคือผลคูณของจำนวนเต็มทั้งหมดตั้งแต่ 1 ถึง `n` เช่น `5! = 5 × 4 × 3 × 2 × 1 = 120` เป็นโจทย์คลาสสิกของการเขียนฟังก์ชันที่เรียกตัวเอง (recursion) เพราะนิยามของมันอ้างถึงตัวเอง ให้เขียน `recursive_factorial` คืนค่า `n!` โดยใช้ recursion และห้ามใช้ลูป

## Requirements

- ต้องใช้การเรียกตัวเอง (recursion)
- ห้ามใช้ loop

## Prototype

```python
recursive_factorial(n: int) -> int
```

## Expected Output

```
> 5
120
```
