testerCode: |
  a = [int(x) for x in input().split()]
  b = [int(x) for x in input().split()]
  for v in merge_sorted(a, b):
      print(v)
testCase:
  - input: "1 3 5\n2 4 6"
    output: "1\n2\n3\n4\n5\n6"
    public: true
  - input: "\n1 2"
    output: "1\n2"
  - input: "1 2\n\n"
    output: "1\n2"
  - input: "1 1 2\n1 3"
    output: "1\n1\n1\n2\n3"
  - input: "5\n5"
    output: "5\n5"

คืน `list` ที่รวม `a` และ `b` (แต่ละชุดเรียงแล้ว) ให้ยังเรียงจากน้อยไปมาก ห้ามใช้ `sort`/`sorted`

## Prototype

```
merge_sorted(a: list[int], b: list[int]) -> list[int]
```

## Expected Output

```

> 1 3 5
> 2 4 6
1
2
3
4
5
6
```
