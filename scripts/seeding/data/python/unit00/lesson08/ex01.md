title: EX01 Binary Search
type: code
testerCode: |
  nums = [int(x) for x in input().split()]
  target = int(input())
  print(binary_search(nums, target))
testCase:
  - input: "1 3 5 7 9\n5"
    output: "2"
    public: true
  - input: "1 2 3 4\n8"
    output: "-1"
  - input: "5\n5"
    output: "0"
  - input: "2 5 8\n5"
    output: "1"
  - input: "1 3 5 7\n3"
    output: "1"
---

คืน index ของ `target` ใน `nums` ที่เรียงจากน้อยไปมากอยู่แล้ว ถ้าไม่เจอคืน `-1` (ห้ามใช้ `index`/`.find`)

## Prototype

```
binary_search(nums: list[int], target: int) -> int
```

## Expected Output

```

> 1 3 5 7 9
> 5
2
```
