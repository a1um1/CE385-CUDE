การค้นหาแบบทวิภาค (binary search) ใช้ประโยชน์จากข้อมูลที่เรียงลำดับแล้วเพื่อตัดข้อมูลออกครึ่งหนึ่งทุกครั้งที่เปรียบเทียบ จึงเร็วกว่าการไล่หาทีละตัวมาก ให้เขียนฟังก์ชันหาตำแหน่ง (index) ของ `target` ใน `nums` ที่เรียงจากน้อยไปมากอยู่แล้ว แล้วคืน `-1` ถ้าไม่พบ โดยห้ามใช้ `index` หรือ `.find`

## Requirements

- `nums` เรียงจากน้อยไปมากอยู่แล้ว
- ถ้าไม่เจอ ให้คืน `-1`
- ห้ามใช้ `index` / `.find`

## Prototype

```python
binary_search(nums: list[int], target: int) -> int
```

## Expected Output

```
> 1 3 5 7 9
> 5
2
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
