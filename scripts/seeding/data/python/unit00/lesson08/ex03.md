โจทย์คลาสสิกที่ฝึกการเชื่อมโยงระหว่างค่ากับตำแหน่งของมัน ให้เขียนฟังก์ชันรับ `list` ของจำนวนเต็มและค่า `target` แล้วคืนตำแหน่ง `(i, j)` ที่ `i < j` และผลรวมของค่าทั้งสองตำแหน่งเท่ากับ `target` โดยรับประกันว่ามีคำตอบเดียวเสมอ และห้ามใช้ลูปซ้อนกัน

## Requirements

- มีคำตอบเดียวเสมอ
- ห้ามใช้ loop ซ้อนกัน

## Prototype

```python
two_sum(nums: list[int], target: int) -> tuple[int, int]
```

## Expected Output

```
> 2 7 11 15
> 9
0 1
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
