คืน `(i, j)` โดย `i < j` และ `nums[i] + nums[j] == target` มีคำตอบเดียว ห้ามใช้ loop ซ้อน

## Prototype

```
two_sum(nums: list[int], target: int) -> tuple[int, int]
```

## Expected Output

```

> 2 7 11 15
> 9
0 1
```
