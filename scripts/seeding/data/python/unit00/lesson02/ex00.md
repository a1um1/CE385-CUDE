# Conditions

โปรแกรมเลือกทำตามเงื่อนไขด้วย `if` / `elif` / `else`\
ตัวดำเนินการเปรียบเทียบให้ผล `True` / `False` ([`==`, `!=`, `>`, `<`, `>=`, `<=`])\
`=` ใช้กำหนดค่า ไม่ใช่การเปรียบเทียบ และโค้ดในบล็อกต้อง indent ให้ตรงกัน

ไปค้นต่อ: `python if elif else`, `python comparison operators`
