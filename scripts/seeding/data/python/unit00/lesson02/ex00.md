# Conditions

โปรแกรมคอมพิวเตอร์ต้องตัดสินใจตามเงื่อนไขเพื่อเลือกทำอย่างใดอย่างหนึ่งจากหลายทาง ตั้งแต่การเช็กสิทธิ์เข้าใช้งาน ไปจนถึงการเลือกเส้นทางที่เร็วที่สุด การเขียนเงื่อนไขให้ถูกต้องจึงเป็นทักษะพื้นฐานที่ขาดไม่ได้

- ตัวดำเนินการเปรียบเทียบให้ผล `True` / `False`: `==`, `!=`, `>`, `<`, `>=`, `<=`
- `=` ใช้กำหนดค่า ไม่ใช่การเปรียบเทียบ
- โค้ดในบล็อกต้อง indent ให้ตรงกัน ไม่งั้นจะ Error

> [!NOTE]\
> Keyword `python if elif else`, `python comparison operators`
