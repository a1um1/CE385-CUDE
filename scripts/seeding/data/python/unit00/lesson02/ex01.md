ปีอธิกสุรทินทำให้เดือนกุมภาพันธ์มี 29 วัน เพื่อให้ปฏิทินตรงกับรอบโคจรจริงของโลก กฎการนับปีอธิกสุรทินมีข้อยกเว้นสองชั้น ไม่ใช่แค่หาร 4 ลงตัวเท่านั้น ให้เขียนฟังก์ชันตรวจสอบปีที่รับเข้ามา แล้วคืน `"Leap"` เมื่อเป็นปีอธิกสุรทิน หรือ `"Common"` เมื่อไม่ใช่

## Requirements

- หาร 4 ลงตัว → ปีอธิกสุรทิน
- ยกเว้น หาร 100 ลงตัว → ไม่ใช่ปีอธิกสุรทิน
- ยกเว้นของข้อยกเว้น หาร 400 ลงตัว → เป็นปีอธิกสุรทิน

## Prototype

```python
leap_year(year: int) -> str
```

## Expected Output

```
> 2000
Leap
```
