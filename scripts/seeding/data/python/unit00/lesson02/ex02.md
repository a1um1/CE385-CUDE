สามเหลี่ยมจำแนกได้จากความยาวของด้านทั้งสาม ถ้าด้านสั้นสองด้านรวมกันไม่ยาวกว่าด้านที่เหลือ จะประกอบเป็นสามเหลี่ยมไม่ได้ ให้เขียนฟังก์ชันคืนชนิดของสามเหลี่ยมจากความยาวสามด้านที่รับเข้ามา ได้แก่ `"Equilateral"`, `"Isosceles"`, `"Scalene"` หรือ `"Invalid"` เมื่อด้านที่รับมาไม่สามารถเป็นสามเหลี่ยมได้

## Requirements

- ด้านเท่ากันทั้งสาม → `"Equilateral"`
- ด้านเท่ากันสองด้าน → `"Isosceles"`
- ด้านไม่เท่ากันเลย → `"Scalene"`
- `"Invalid"` เมื่อด้านใดด้านหนึ่งไม่เกิน 0 หรือผลรวมสองด้านไม่มากกว่าด้านที่เหลือ

## Prototype

```python
triangle_kind(a: int, b: int, c: int) -> str
```

## Expected Output

```
> 3
> 3
> 3
Equilateral
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
