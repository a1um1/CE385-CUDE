ระบบหลายแบบจัดกลุ่มผู้ใช้ตามช่วงอายุเพื่อปรับเนื้อหาหรือสิทธิ์ให้เหมาะสม ตั้งแต่เด็กเล็กไปจนถึงผู้สูงอายุ ให้เขียนฟังก์ชันรับอายุเป็นจำนวนเต็ม แล้วคืนชื่อกลุ่มอายุตามช่วงที่กำหนด โดยแต่ละค่าต้องตกอยู่ในกลุ่มใดกลุ่มหนึ่งเท่านั้น ไม่ทับกันหรือมีช่องว่าง

## Requirements

- `0-12` → `"Child"`
- `13-19` → `"Teen"`
- `20-59` → `"Adult"`
- `60` ขึ้นไป → `"Senior"`

## Prototype

```python
age_group(age: int) -> str
```

## Expected Output

```
> 10
Child
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
