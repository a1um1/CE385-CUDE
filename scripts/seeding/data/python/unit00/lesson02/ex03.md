การเลือกค่าที่ดีที่สุดจากชุดข้อมูลเป็นปัญหาพื้นฐานที่เจอเกือบทุกโปรแกรม ให้เขียนฟังก์ชันหาค่าที่มากที่สุดจากจำนวนเต็มสามตัวที่รับเข้ามา ค่าที่รับอาจเป็นค่าติดลบหรือมีค่าซ้ำกันได้ เพื่อฝึกคิดแบบเปรียบเทียบเป็นลำดับ โดยไม่พึ่งพา `max` หรือ `sorted` ที่ Python มีให้

## Requirements

- ห้ามใช้ `max` และ `sorted`
- ค่าที่รับมาอาจติดลบได้

## Prototype

```python
max_of_three(a: int, b: int, c: int) -> int
```

## Expected Output

```
> 3
> 9
> 5
9
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
