รหัสซีซาร์เป็นวิธีการเข้ารหัสที่เก่าแก่ที่สุดวิธีหนึ่ง โดยเลื่อนตัวอักษรแต่ละตัวไปจำนวนตำแหน่งที่กำหนด เช่น เลื่อน 1 ทำให้ `abc` กลายเป็น `bcd` และเลื่อน 3 ทำให้ `xyz` วนกลับเป็น `abc` ให้เขียนฟังก์ชันเลื่อนเฉพาะตัวอักษร `a-z` ส่วนตัวอักษรอื่นคงเดิม

## Requirements

- เลื่อนเฉพาะตัวอักษร `a`–`z` เมื่อเลย `z` ให้วนกลับไป `a`
- ตัวอักษรอื่นที่ไม่ใช่ `a`–`z` คงเดิม

## Prototype

```python
caesar(text: str, shift: int) -> str
```

## Expected Output

```
> abc
> 1
bcd
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
