# Lists & Strings

ข้อมูลที่โปรแกรมจัดการส่วนใหญ่เป็นชุดของค่า (`list`) หรือชุดของตัวอักษร (`str`) ตั้งแต่รายชื่อนักเรียนไปจนถึงข้อความในบทความ การสร้าง เข้าถึง และแก้ไขข้อมูลสองแบบนี้จึงเป็นทักษะที่ใช้งานในทุกโปรเจกต์

- `list` เก็บหลายค่า เริ่มนับ index จาก 0 และ `len()` บอกจำนวนสมาชิก
- `str` เข้าถึงทีละตัวอักษรได้เหมือน list
- slicing `[start:stop:step]` ใช้ได้กับทั้ง `list` และ `str`
- `split()` แยกข้อความเป็น list ตามตัวคั่น (ค่าเริ่มต้นคือช่องว่าง)

> [!NOTE]\
> Keyword `python list methods`, `python string slicing`, `python str.split`
