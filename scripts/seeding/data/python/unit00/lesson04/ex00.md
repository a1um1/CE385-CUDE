# Lists & Strings

`list` เก็บหลายค่า เริ่มนับ index จาก 0 และ `len()` บอกจำนวนสมาชิก\
`str` เข้าถึงทีละตัวอักษรได้เหมือน list และ slicing `[start:stop:step]` ใช้กับทั้งสองแบบ\
`split()` แยกข้อความเป็น list ตามตัวคั่น (default ช่องว่าง)

ไปค้นต่อ: `python list methods`, `python string slicing`, `python str.split`
