การนับจำนวนคำต้องนิยามให้ชัดก่อนว่าคำคืออะไร และจัดการช่องว่างที่หลายตำแหน่งอย่างไร เช่น ข้อความที่ขึ้นต้นและลงท้ายด้วยช่องว่าง ใช้เป็นพื้นฐานของงานวิเคราะห์ข้อความ ให้เขียนฟังก์ชันรับข้อความ แล้วคืนจำนวนคำ โดยคำคือกลุ่มตัวอักษรหรือตัวเลขที่คั่นด้วยช่องว่าง

- คำคือกลุ่มตัวอักษร/ตัวเลขที่คั่นด้วยช่องว่าง
- ช่องว่างที่ติดกันหลายตัวนับเป็นตัวคั่นเดียว

## Prototype

```python
word_count(text: str) -> int
```
