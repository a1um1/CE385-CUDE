การบีบอัดแบบ RLE (Run-Length Encoding) ย่อข้อมูลที่ตัวอักษรซ้ำกันเป็นช่วงยาว โดยแทนด้วยตัวอักษรตามด้วยจำนวนครั้ง เช่น `aaabbc` กลายเป็น `a3b2c1` ใช้กับรูปภาพและเสียงที่มีข้อมูลซ้ำกันเยอะ ให้เขียนฟังก์ชันเข้ารหัสข้อความด้วยวิธีนี้ โดยตัวที่ซ้ำกันแต่ไม่ได้ติดกันต้องนับแยก

## Requirements

- ตัวอักษรตามด้วยจำนวนที่ซ้ำติดกัน
- นับเฉพาะตัวที่ซ้ำติดกันจริง ๆ ถ้าตัวเดิมโผล่อีกทีหลังห่างกัน ให้นับแยกกัน

## Prototype

```python
run_length_encode(text: str) -> str
```

## Expected Output

```
> aaabbc
a3b2c1
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
