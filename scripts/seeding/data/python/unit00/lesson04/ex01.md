พาลินโดรมคือข้อความที่อ่านจากหน้าไปหลังและหลังไปหน้ากลับได้เหมือนกัน เช่น `racecar` หรือ `A man a plan a canal Panama` การตรวจสอบแบบนี้พบได้ในงานตรวจสอบข้อมูลและเกมคำศัพท์ ให้เขียนฟังก์ชันตรวจสอบว่า `text` ที่รับเข้ามาเป็นพาลินโดรมหรือไม่ โดยไม่สนใจช่องว่างและตัวพิมพ์เล็ก/ใหญ่ แล้วคืน `True` หรือ `False`

## Requirements

- ไม่สนใจช่องว่าง
- ไม่สนใจตัวพิมพ์เล็ก/ใหญ่

## Prototype

```python
is_palindrome(text: str) -> bool
```

## Expected Output

```
> racecar
True
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
