เทคนิค two pointers ใช้ตัวชี้สองตำแหน่งที่ค่อย ๆ เคลื่อนเข้าหากันเพื่อหาคำตอบโดยไม่ต้องไล่ตรวจทุกคู่ ให้เขียนฟังก์ชันรับ `nums` ที่เรียงจากน้อยไปมากอยู่แล้วกับค่า `target` แล้วคืนสองค่าที่บวกกันได้ `target` โดยรับประกันว่ามีคำตอบเดียวเสมอ ห้ามใช้ dict และห้ามใช้ nested loop

## Requirements

- `nums` เรียงจากน้อยไปมากอยู่แล้ว และมีคำตอบเดียวเสมอ
- ให้ใช้ two pointers ชี้หัว–ท้ายเข้าหากัน
- ห้ามใช้ `dict` และห้ามใช้ nested loop

## Prototype

```python
two_pointer_sum(nums: list[int], target: int) -> tuple[int, int]
```

## Expected Output

```
> 1 2 4 7 11
> 13
2 11
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
