  nums = [int(x) for x in input().split()]
  target = int(input())
  a, b = two_pointer_sum(nums, target)

`nums` เรียงจากน้อยไปมากอยู่แล้ว คืน `(a, b)` — สองค่าที่บวกกันได้ `target` (มีคำตอบเดียวเสมอ) ใช้ two pointers ชี้หัว–ท้าย เข้าหากัน ห้ามใช้ dict และห้ามใช้ nested loop

## Prototype

```
two_pointer_sum(nums: list[int], target: int) -> tuple[int, int]
```

## Expected Output

```

> 1 2 4 7 11
> 13
2 11
```
