การเรียงข้อมูลแบบ selection sort เป็นอัลกอริทึมการเรียงที่เข้าใจง่ายที่สุดวิธีหนึ่ง โดยวนหาค่าน้อยที่สุดที่เหลืออยู่มาวางไว้ตำแหน่งหน้าสุดทีละรอบ จนกว่าข้อมูลทั้งหมดจะเรียงครบ ให้เขียนฟังก์ชันคืน `nums` ที่เรียงจากน้อยไปมากด้วยวิธีนี้ โดยห้ามใช้ `sorted` หรือ `sort`

## Requirements

- วนหาค่าน้อยสุดที่เหลือ แล้ววางไว้หน้าสุดทีละรอบ
- ห้ามใช้ `sorted` / `sort`

## Prototype

```python
selection_sort(nums: list[int]) -> list[int]
```

## Expected Output

```
> 5 1 4 2 3
1
2
3
4
5
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
