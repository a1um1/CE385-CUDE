  nums = [int(x) for x in input().split()]

คืน `nums` ที่เรียงจากน้อยไปมากด้วย selection sort — วนหาค่าน้อยสุดวางไว้หน้าสุดทีละรอบ ห้ามใช้ `sorted`/`sort`

## Prototype

```
selection_sort(nums: list[int]) -> list[int]
```

## Expected Output

```

> 5 1 4 2 3
1
2
3
4
5
```
