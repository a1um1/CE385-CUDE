หน้าต่างเลื่อนเหมาะกับปัญหาที่ต้องการช่วงข้อมูล (subarray) ที่มีคุณสมบัติบางอย่าง เช่น ผลรวมถึงค่าเป้าหมาย ให้เขียนฟังก์ชันรับ `list` ของจำนวนเต็มที่ไม่ติดลบกับค่า `k` แล้วคืน `True` ถ้ามีช่วงสมาชิกที่ติดกันซึ่งบวกกันได้ `k`

## Requirements

- ค่าทุกตัวเป็นจำนวนเต็มไม่ติดลบ
- ให้ใช้หน้าต่างเลื่อน — ขยายเมื่อผลรวมน้อยเกิน ตัดหัวเมื่อเกิน

## Prototype

```python
subarray_sum(nums: list[int], k: int) -> bool
```

## Expected Output

```
> 1 2 3 4
> 6
True
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
