  nums = [int(x) for x in input().split()]
  k = int(input())
  print(subarray_sum(nums, k))
testCase:
  - input: "1 2 3 4\n6"
    output: "True"
    public: true
  - input: "1 2 3\n7"
    output: "False"
    public: true
  - input: "5 1 2 3\n6"
    output: "True"
  - input: "3\n3"
    output: "True"
  - input: "2 4\n5"
    output: "False"

คืน `True` ถ้ามี subarray (สมาชิกเรียงติดกัน) ที่บวกกันได้ `k` — ค่าทุกตัวเป็นจำนวนเต็มไม่ติดลบ ใช้หน้าต่างเลื่อน (ขยายเมื่อน้อยเกิน ตัดหัวเมื่อเกิน)

## Prototype

```
subarray_sum(nums: list[int], k: int) -> bool
```

## Expected Output

```

> 1 2 3 4
> 6
True
```
