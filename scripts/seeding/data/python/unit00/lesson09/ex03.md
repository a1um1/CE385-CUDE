---
title: EX03 Balanced Brackets
type: code
testerCode: |
  print(balanced(input()))
testCase:
  - input: "()[]{}"
    output: "True"
    public: true
  - input: "([)]"
    output: "False"
    public: true
  - input: "(]"
    output: "False"
  - input: "\n"
    output: "True"
  - input: "((()))"
    output: "True"
---

คืน `True` ถ้าวงเล็บ `()`, `[]`, `{}` ใน `text` เปิด–ปิดถูกต้อง (ข้อความว่างถือว่าถูกต้อง) ใช้ stack — ตัวเปิด push, ตัวปิดต้องตรงกับตัวบนสุด

## Prototype

```
balanced(text: str) -> bool
```

## Expected Output

```

> ()[]{}
True
```
