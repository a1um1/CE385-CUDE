การตรวจสอบว่าวงเล็บเปิดปิดถูกต้องเป็นปัญหาที่พบในตัวแปลภาษา (compiler) และเครื่องมือตรวจสอบโค้ด ให้เขียนฟังก์ชันตรวจสอบว่าวงเล็บ `()`, `[]`, `{}` ในข้อความเปิดปิดตรงกันและไม่สลับชนิดกันหรือไม่ โดยใช้ stack และข้อความว่างถือว่าถูกต้อง

## Requirements

- ข้อความว่างถือว่าถูกต้อง
- ให้ใช้ stack — ตัวเปิด push เก็บ ตัวปิดต้องตรงกับตัวบนสุด

## Prototype

```python
balanced(text: str) -> bool
```

## Expected Output

```
> ()[]{}
True
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
