การนับวิธีขึ้นบันไดซ่อนลำดับฟีโบนักชีไว้ข้างใน และเป็นตัวอย่างของการเขียน recursion ที่มี memoization เพื่อไม่ให้คำนวณค่าเดิมซ้ำ ให้เขียนฟังก์ชันรับจำนวนขั้นบันได `n` โดยแต่ละก้าวเดินได้ 1 หรือ 2 ขั้น แล้วคืนจำนวนวิธีทั้งหมดที่ขึ้นถึงขั้นบนสุด

## Requirements

- ตัวอย่าง: `n=3 → 3` (111, 12, 21)
- เขียนด้วย recursion **พร้อม memoization** (dict เก็บผลที่คำนวณแล้ว ห้ามคำนวณซ้ำ)

## Prototype

```python
climb_ways(n: int) -> int
```

## Expected Output

```
> 3
3
```
