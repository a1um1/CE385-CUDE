การหาช่วงข้อมูลที่ยาวที่สุดภายใต้เงื่อนไขบางอย่างเข้ากับเทคนิค sliding window ซึ่งเลื่อนขอบเขตการดูข้อมูลโดยไม่ต้องเริ่มใหม่ทุกครั้ง ให้เขียนฟังก์ชันรับข้อความ แล้วคืนความยาวของช่วงตัวอักษรที่ติดกันยาวที่สุดซึ่งไม่มีตัวอักษรซ้ำกัน

## Requirements

- substring ต้องเป็นตัวอักษรที่ติดกันจริงในข้อความ
- ให้เลื่อนหน้าต่าง (sliding window) ด้วย `dict` เก็บตำแหน่งล่าสุดของตัวอักษร

## Prototype

```python
longest_unique_run(text: str) -> int
```

## Expected Output

```
> abcabcbb
3
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
