  print(longest_unique_run(input()))
testCase:
  - input: "abcabcbb"
    output: "3"
    public: true
  - input: "bbbbb"
    output: "1"
    public: true
  - input: "\n"
    output: "0"
  - input: "pwwkew"
    output: "3"
  - input: "abcdef"
    output: "6"

คืนความยาวของ substring เรียงติดกันที่ยาวที่สุดซึ่งไม่มีตัวอักษรซ้ำ เช่น `abcabcbb → 3` (abc) เลื่อนหน้าต่าง (sliding window) ด้วย dict เก็บตำแหน่งล่าสุดของตัวอักษร

## Prototype

```
longest_unique_run(text: str) -> int
```

## Expected Output

```

> abcabcbb
3
```
