# Loops

ทำซ้ำด้วย `for` (รู้จำนวนรอบ หรือเดินผ่านข้อมูลทีละตัว) หรือ `while` (รู้แค่เงื่อนไขหยุด)\
`range(start, stop)` นับไม่รวมตัวท้าย\
ใน `while` ต้องมีค่าที่เปลี่ยนทุก ๆ รอบ ไม่งั้นติด Infinite Loop

ไปค้นต่อ: `python for range`, `python while loop`, `python break continue`
