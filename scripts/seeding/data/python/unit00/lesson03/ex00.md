# Loops

การประมวลผลข้อมูลจำนวนมากแทบทุกงานต้องวนซ้ำ ตั้งแต่การไล่นับเลขไปจนถึงการอ่านข้อมูลทีละบรรทัด การเลือกลูปให้เข้ากับงานจะทำให้โค้ดสั้นลงและอ่านเข้าใจง่ายขึ้น

- `for` เหมาะกับงานที่รู้จำนวนรอบ หรือเดินผ่านข้อมูลทีละตัว
- `while` เหมาะกับงานที่รู้แค่เงื่อนไขหยุด
- `range(start, stop)` นับไม่รวมตัวท้าย
- ใน `while` ต้องมีค่าที่เปลี่ยนทุก ๆ รอบ ไม่งั้นติด Infinite Loop

> [!NOTE]\
> Keyword `python for range`, `python while loop`, `python break continue`
