การแยกหลักของตัวเลขออกมาทีละหลักเป็นทักษะที่แฝงอยู่ในโจทย์หลายข้อ เช่น การตรวจเลขบัตรประชาชน หรือการตรวจสอบความถูกต้องของเลขบัญชี ให้เขียนฟังก์ชันรับจำนวนเต็ม `n` ที่มีกี่หลักก็ได้ แล้วคืนผลรวมของทุกหลัก เช่น 385 ได้ผลรวม 16

## Requirements

- ถอดหลักทีละหลักจนกว่าจะหมด
- ถ้าไม่มีหลักให้บวก ให้คืน 0

## Prototype

```python
digit_sum(n: int) -> int
```

## Expected Output

```
> 385
16
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
