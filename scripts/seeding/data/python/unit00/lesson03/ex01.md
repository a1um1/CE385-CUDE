จำนวนเฉพาะคือจำนวนเต็มที่มากกว่าหนึ่งและหารลงตัวเฉพาะ 1 กับตัวเองเท่านั้น การตรวจว่าจำนวนหนึ่งเป็นจำนวนเฉพาะหรือไม่เป็นพื้นฐานของอัลกอริทึมด้านความปลอดภัยและการเข้ารหัส ให้เขียนฟังก์ชันตรวจสอบ `n` ที่รับเข้ามา แล้วคืน `"Prime"` เมื่อเป็นจำนวนเฉพาะ หรือ `"Not Prime"` เมื่อไม่ใช่

## Requirements

- จำนวนเฉพาะคือจำนวนเต็ม `n ≥ 2` ที่หารลงตัวเฉพาะ 1 กับตัวเอง
- ค่าที่น้อยกว่า 2 ไม่นับเป็นจำนวนเฉพาะ

## Prototype

```python
is_prime(n: int) -> str
```

## Expected Output

```
> 7
Prime
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
