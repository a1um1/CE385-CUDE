ตัวหารร่วมมาก (GCD) คือจำนวนเต็มที่มากที่สุดที่หารทั้งสองจำนวนลงตัวโดยไม่เหลือเศษ ใช้ในการย่อเศษส่วน หาเวลารอบร่วม และปัญหาทางคณิตศาสตร์อีกมาก ให้เขียนฟังก์ชันหา GCD ของ `a` และ `b` ด้วยวิธีของตัวเอง เช่น การหารเอาเศษซ้ำ โดยไม่ใช้ `math.gcd`

## Requirements

- ห้ามใช้ `math.gcd`
- ให้หาด้วยวิธีของตัวเอง เช่น การหารเอาเศษซ้ำ

## Prototype

```python
gcd(a: int, b: int) -> int
```

## Expected Output

```
> 12
> 18
6
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
