การสร้างผลลัพธ์ที่ยืดหยุ่นตามขนาดข้อมูลเป็นทักษะพื้นฐานของการทำงานกับโครงสร้างข้อมูล ให้เขียนฟังก์ชันสร้าง `list` ของข้อความที่วาดรูปสามเหลี่ยมจากเครื่องหมาย `*` จำนวน `n` แถว โดยแถวแรกมีหนึ่งตัวและยาวขึ้นหนึ่งตัวในแต่ละแถว

## Requirements

- แถวแรกมี `*` หนึ่งตัว แถวถัดไปเพิ่มทีละหนึ่งตัว
- แต่ละสมาชิกใน `list` คือหนึ่งแถว ไม่มีช่องว่าง

## Prototype

```python
pyramid(n: int) -> list[str]
```

## Expected Output

```
> 3
*
**
***
```

> [!NOTE]\
> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
