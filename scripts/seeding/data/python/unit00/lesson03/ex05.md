ลำดับฟีโบนักชีคือชุดตัวเลขที่ตัวถัดไปเกิดจากผลบวกของสองตัวก่อนหน้า เริ่มจาก 0 และ 1 ตามลำดับ เช่น 0, 1, 1, 2, 3, 5, 8 เป็นรูปแบบที่พบในธรรมชาติและอัลกอริทึมหลายแบบ ให้เขียนฟังก์ชันคืนค่า Fibonacci ตัวที่ `n`

## Requirements

- `fib(0) = 0`, `fib(1) = 1`
- ตัวถัดไปคือผลบวกของสองตัวก่อนหน้า: `fib(n) = fib(n-1) + fib(n-2)`

## Prototype

```python
fib(n: int) -> int
```

## Expected Output

```
> 0
0
```

> ตัวอย่างที่ให้มาอาจไม่ครบทุกกรณี ระบบจะทดสอบด้วยเคสอื่นที่ซ่อนไว้ด้วย
