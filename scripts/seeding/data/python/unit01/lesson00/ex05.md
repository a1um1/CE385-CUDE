testCase:
  - input: "-7"
    output: "7"
  - input: "12"

  - input
  - int
  - print

รับจำนวนเต็ม แล้วแสดงค่าสัมบูรณ์ (ค่าที่ไม่ติดลบ) ของจำนวนนั้น **โดยห้ามใช้ Function `abs`**

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> -7
7
```

> [!TIP]\
> ถ้าค่าน้อยกว่า 0 ให้คูณด้วย `-1`
