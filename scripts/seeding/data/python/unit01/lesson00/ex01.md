---
title: EX01 Even or Odd
type: code
testCase:
  - input: "4"
    output: "Even"
  - input: "7"
    output: "Odd"
  - input: "0"
    output: "Even"
allowedFunctions:
  - input
  - int
  - print
---

รับจำนวนเต็ม แล้วตรวจว่าเป็นเลขคู่หรือเลขคี่

- ถ้าเป็นเลขคู่ ให้แสดง `Even`
- ถ้าเป็นเลขคี่ ให้แสดง `Odd`

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> 4
Even
```

> [!TIP]\
> ตรวจด้วยเงื่อนไข `n % 2 == 0` โดยใช้ `if` / `else`
