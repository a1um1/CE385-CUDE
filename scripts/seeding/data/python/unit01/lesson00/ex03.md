title: EX03 Grade
type: code
testCase:
  - input: "85"
    output: "A"
  - input: "72"
    output: "B"
  - input: "60"
    output: "C"
  - input: "45"
    output: "F"
allowedFunctions:
  - input
  - int
  - print
---

รับคะแนนสอบ (จำนวนเต็ม 0-100) แล้วแสดงเกรดตามเกณฑ์

- 80 ขึ้นไป → `A`
- 70-79 → `B`
- 60-69 → `C`
- 50-59 → `D`
- ต่ำกว่า 50 → `F`

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> 85
A
```

> [!TIP]\
> ใช้ `elif` เพื่อตรวจเงื่อนไขหลายระดับ โดยเรียงจากมากไปน้อย
