title: EX04 Sign
type: code
testCase:
  - input: "5"
    output: "Positive"
  - input: "-3"
    output: "Negative"
  - input: "0"
    output: "Zero"
allowedFunctions:
  - input
  - int
  - print
---

รับจำนวนเต็ม แล้วบอกว่าเป็นจำนวนบวก ลบ หรือศูนย์

- มากกว่า 0 → `Positive`
- น้อยกว่า 0 → `Negative`
- เท่ากับ 0 → `Zero`

## Allowed Functions

`input`, `int`, `print`

## Expected Output

```
> -3
Negative
```
