# ก่อนลงมือ: การตัดสินใจด้วย Conditions

โปรแกรมจะฉลาดขึ้นได้ เมื่อมัน "เลือกทำ" ตามเงื่อนไข\
การเลือกแบบนี้ใช้ `if` / `elif` / `else`

## เปรียบเทียบก่อนตัดสินใจ

ตัวดำเนินการเปรียบเทียบจะให้ผลเป็น `True` หรือ `False`

| ตัวดำเนินการ | ความหมาย |
| --- | --- |
| `==` | เท่ากัน |
| `!=` | ไม่เท่ากัน |
| `>` `<` | มากกว่า / น้อยกว่า |
| `>=` `<=` | มากกว่าหรือเท่ากับ / น้อยกว่าหรือเท่ากับ |

> [!CAUTION]\
> `=` ใช้กำหนดค่า ส่วน `==` ใช้เปรียบเทียบ อย่าสับสน!

## รูปแบบของ if

```python
score = int(input())

if score >= 80:
    print("A")
elif score >= 70:
    print("B")
else:
    print("F")
```

- โปรแกรมจะตรวจจากบนลงล่าง เจอเงื่อนไขแรกที่เป็นจริงแล้วหยุด
- `elif` มีกี่อันก็ได้ ส่วน `else` ไว้รับกรณีที่เหลือทั้งหมด

> [!NOTE]\
> **การย่อหน้า (indent)** สำคัญมากใน Python ต้องเว้น 4 เคาะให้ตรงกันเสมอ
> ถ้า indent ผิด โปรแกรมจะ Error ทันที ไม่ใช่เรื่องน่ากลัว ลองแก้แล้วรันใหม่ได้เลย
