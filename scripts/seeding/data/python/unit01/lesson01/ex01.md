title: EX01 Sum 1 to N
type: code
testCase:
  - input: "5"
    output: "15"
  - input: "1"
    output: "1"
  - input: "10"
    output: "55"
allowedFunctions:
  - input
  - int
  - range
  - print
---

รับจำนวนเต็มบวก `n` แล้วแสดงผลรวมของจำนวนเต็มตั้งแต่ 1 ถึง `n`

ตัวอย่าง: n = 5 → 1 + 2 + 3 + 4 + 5 = 15

## Allowed Functions

`input`, `int`, `range`, `print`

## Expected Output

```
> 5
15
```

> [!TIP]\
> ใช้ `for` คู่กับ `range` แล้วเก็บผลรวมไว้ในตัวแปร
