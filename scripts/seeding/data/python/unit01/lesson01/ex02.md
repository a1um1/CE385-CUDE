---
title: EX02 Count Up
type: code
testCase:
  - input: "3"
    output: "1\n2\n3"
  - input: "5"
    output: "1\n2\n3\n4\n5"
allowedFunctions:
  - input
  - int
  - range
  - print
---

รับจำนวนเต็มบวก `n` แล้วแสดงตัวเลขตั้งแต่ 1 ถึง `n` บรรทัดละ 1 จำนวน

## Allowed Functions

`input`, `int`, `range`, `print`

## Expected Output

```
> 3
1
2
3
```
