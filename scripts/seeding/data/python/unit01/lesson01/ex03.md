รับจำนวนเต็ม `n` แล้วแสดงค่า `n!` (แฟกทอเรียล)

ตัวอย่าง: 5! = 5 × 4 × 3 × 2 × 1 = 120

กำหนดให้ 0! = 1

## Allowed Functions

`input`, `int`, `range`, `print`

## Expected Output

```
> 5
120
```
