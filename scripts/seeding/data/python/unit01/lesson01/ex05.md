---
title: EX05 FizzBuzz
type: code
testCase:
  - input: "5"
    output: "1\n2\nFizz\n4\nBuzz"
  - input: "15"
    output: "1\n2\nFizz\n4\nBuzz\nFizz\n7\n8\nFizz\nBuzz\n11\nFizz\n13\n14\nFizzBuzz"
allowedFunctions:
  - input
  - int
  - range
  - print
---

รับจำนวนเต็มบวก `n` แล้วแสดงตัวเลขตั้งแต่ 1 ถึง `n` ตามกติกา

- หาร 3 ลงตัว → `Fizz`
- หาร 5 ลงตัว → `Buzz`
- หารทั้ง 3 และ 5 ลงตัว → `FizzBuzz`
- นอกนั้น → แสดงตัวเลขนั้น

## Allowed Functions

`input`, `int`, `range`, `print`

## Expected Output

```
> 5
1
2
Fizz
4
Buzz
```

> [!CAUTION]\
> ต้องตรวจเงื่อนไขหารทั้ง 3 และ 5 ลงตัว (`FizzBuzz`) เป็นกรณีแรก ไม่อย่างนั้นจะได้ผลลัพธ์ผิด
