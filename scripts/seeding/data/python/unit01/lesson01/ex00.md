# ก่อนลงมือ: การทำซ้ำด้วย Loops

งานที่ต้องทำซ้ำ ๆ หลายครั้ง โปรแกรมจะทำให้เราได้ง่าย ๆ ด้วย **loop**\
เราไม่ต้องเขียนบรรทัดเดิมซ้ำสิบรอบ แค่บอกว่า "ทำซ้ำ"

## for กับ range

```python
for i in range(1, 4):
    print(i)
```

ผลลัพธ์:

```
1
2
3
```

`range(1, 4)` ให้ค่า `1, 2, 3` (ตัวท้ายไม่รวม) แล้วโค้ดที่ย่อหน้าจะถูกทำซ้ำในแต่ละรอบ

## while

ใช้เมื่อยังไม่รู้จำนวนรอบที่แน่นอน แต่รู้เงื่อนไขที่จะหยุด

```python
n = 5
while n > 0:
    print(n)
    n = n - 1
```

ผลลัพธ์คือ `5 4 3 2 1`

> [!CAUTION]\
> ถ้าเงื่อนไขของ `while` ไม่มีวันเป็นเท็จ โปรแกรมจะวนไม่จบ (Infinite Loop)
> ถ้าเจออาการนี้ กดหยุดแล้วกลับไปดูว่าค่าที่ใช้ตรวจเปลี่ยนไปทุกรอบหรือไม่
