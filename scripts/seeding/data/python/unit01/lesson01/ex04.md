title: EX04 Reverse Digits
type: code
testCase:
  - input: "1234"
    output: "4321"
  - input: "7"
    output: "7"
  - input: "1000"
    output: "0001"
allowedFunctions:
  - input
  - int
  - str
  - print
---

รับจำนวนเต็มบวก แล้วแสดงตัวเลขที่กลับหลักกัน (หลักแรกไปอยู่ท้ายสุด)

ตัวอย่าง: 1234 → 4321

## Allowed Functions

`input`, `int`, `str`, `print`

## Expected Output

```
> 1234
4321
```

> [!TIP]\
> ใช้ `while` ดึงหลักสุดท้ายด้วย `% 10` แล้วตัดทิ้งด้วย `// 10` จนกว่าค่าจะเป็น 0
> นำหลักที่ได้มาต่อกันเป็นข้อความก่อนแสดงผล
