---
title: EX02 Max in List
type: code
testCase:
  - input: "3\n4\n9\n2"
    output: "9"
  - input: "5\n-1\n-5\n-3\n-2\n-4"
    output: "-1"
allowedFunctions:
  - input
  - int
  - range
  - print
---

รับจำนวนเต็ม `n` ตามด้วยตัวเลขอีก `n` จำนวน แล้วแสดงค่าที่มากที่สุด

ห้ามใช้ Function `max`

## Allowed Functions

`input`, `int`, `range`, `print`

## Expected Output

```
> 3
> 4
> 9
> 2
9
```

> [!TIP]\
> เริ่มต้นด้วยค่าตัวแรกเป็นค่ามากสุด แล้ววนเปรียบเทียบกับตัวที่เหลือ
