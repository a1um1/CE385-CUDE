# ก่อนลงมือ: เก็บข้อมูลหลาย ๆ ค่า

บางทีเรามีข้อมูลหลายตัว เช่น คะแนนของเพื่อนทั้งห้อง\
เรามักเก็บไว้ใน **list** ส่วนข้อความยาว ๆ ก็จัดการได้เหมือนเป็นชุดตัวอักษร

## List

```python
nums = [10, 20, 30]
print(nums[0])     # 10 (นับจาก 0)
print(len(nums))   # 3
```

- เข้าถึงด้วย index ในวงเล็บเหลี่ยม เริ่มนับที่ `0`
- `len()` บอกจำนวนสมาชิก
- วนอ่านทีละตัวด้วย `for`

## String

ข้อความก็เข้าถึงทีละตัวอักษรได้เหมือน list

```python
word = "CUDE"
print(word[0])      # C
print(word[::-1])   # EDUC  (กลับข้อความ)
print(word.lower()) # cude  (ตัวพิมพ์เล็ก)
```

> [!TIP]\
> ถ้าทำโจทย์เรื่องข้อความไม่ได้ ลอง **พิมพ์ข้อความออกมาตู** ก่อนว่าแต่ละตัวเป็นอะไร
> การ Debug ด้วยการแสดงผลทีละขั้นเป็นวิธีที่โปรแกรมเมอร์ใช้จริง
