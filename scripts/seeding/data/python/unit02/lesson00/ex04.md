---
title: EX04 Count Vowels
type: code
testCase:
  - input: "hello"
    output: "2"
  - input: "CUDE"
    output: "2"
  - input: "xyz"
    output: "0"
allowedFunctions:
  - input
  - print
---

รับข้อความ แล้วนับจำนวนสระ (`a`, `e`, `i`, `o`, `u`) โดยไม่สนใจตัวพิมพ์เล็ก-ใหญ่

## Allowed Functions

`input`, `print`

## Expected Output

```
> hello
2
```

> [!TIP]\
> แปลงข้อความให้เป็นตัวพิมพ์เล็กด้วย `.lower()` แล้ววนตรวจทีละตัวอักษร
