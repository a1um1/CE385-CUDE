---
title: EX05 Count Even
type: code
testCase:
  - input: "5\n1\n2\n3\n4\n6"
    output: "3"
  - input: "3\n1\n3\n5"
    output: "0"
allowedFunctions:
  - input
  - int
  - range
  - print
---

รับจำนวนเต็ม `n` ตามด้วยตัวเลขอีก `n` จำนวน แล้วนับว่ามีจำนวนคู่กี่จำนวน

## Allowed Functions

`input`, `int`, `range`, `print`

## Expected Output

```
> 5
> 1
> 2
> 3
> 4
> 6
3
```
