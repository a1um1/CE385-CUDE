type: code
testCase:
  - input: "hello"
    output: "olleh"
  - input: "CUDE"
    output: "EDUC"
  - input: "a"
    output: "a"
allowedFunctions:
  - input
  - print
---

## Allowed Functions

`input`, `print`

## Expected Output

```
> hello
olleh
```

> ใช้ Slicing `[::-1]` เพื่อกลับข้อความ
