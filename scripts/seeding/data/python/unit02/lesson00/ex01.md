บรรทัดแรกรับจำนวนเต็ม `n` (จำนวนตัวเลข)
จากนั้นอีก `n` บรรทัดเป็นตัวเลขทีละจำนวน

ให้แสดงผลรวมของตัวเลขทั้งหมด

## Allowed Functions

`input`, `int`, `range`, `print`

## Expected Output

```
> 3
> 1
> 2
> 3
6
```
